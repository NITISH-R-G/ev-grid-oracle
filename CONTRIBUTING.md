# Contributing Guide

Welcome! We appreciate your interest in contributing.

## Getting Started
1. Fork the repo.
2. Clone it locally.
3. Install dependencies (`uv sync --all-extras` for Python, `npm ci` for web).
4. Make your changes in a new branch.

## Submitting changes
Ensure tests pass. Open a pull request. We have automated bots and tools that will help you.

Thanks for contributing!

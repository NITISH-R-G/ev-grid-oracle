# Contributing to this project

First off, thanks for taking the time to contribute!

## Development Setup

1. Clone the repository.
2. Ensure you have `uv` installed.
3. Run `uv pip install -e ".[dev]"` to install Python dependencies.
4. For frontend, navigate to `web/` and run `npm install`.

## Commit Guidelines

- Follow semantic commit messages.
- Ensure all tests and linting pass before committing.

## Pull Requests

- Keep PRs small and focused.
- Ensure PRs have a clear description.
- Follow the PR template.

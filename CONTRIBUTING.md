# Contributing Guidelines

Thank you for your interest in contributing! We welcome all contributions.

## Development Process

1. Fork the repository
2. Create your feature branch (\`git checkout -b feature/amazing-feature\`)
3. Commit your changes (\`git commit -m 'feat: add amazing feature'\`)
4. Push to the branch (\`git push origin feature/amazing-feature\`)
5. Open a Pull Request

## Automated Checks

When you open a PR, our automated systems will:
- Check formatting and linting (Ruff, Prettier)
- Run tests (Pytest)
- Review code quality (Mypy, Vulture, Radon)
- Perform security scans (Bandit, Trufflehog)
- Use our AI PR Agent to review your code and suggest improvements

Please make sure all status checks pass before requesting a review.

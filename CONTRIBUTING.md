# Contributing Guidelines

Thank you for your interest in contributing to this project!

## Getting Started

1. Fork the repository and create your branch from `main`.
2. Install the required dependencies using `uv pip install -e ".[dev,demo]"`.
3. Read the documentation in `README.md` to get familiar with the project structure.

## Code Standards

- This project strictly follows Python typing and styling guidelines.
- Use `ruff` for code formatting and linting.
- Run tests using `pytest` before submitting a PR.
- Use `validate-submission.sh` to run the full suite of local submission checks.

## Submitting Pull Requests

1. Ensure all CI checks and tests pass locally.
2. Provide a clear and descriptive PR title and description.
3. Reference any related issues (e.g., "Fixes #123").

We welcome contributions of all sizes and skill levels!

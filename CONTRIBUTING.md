# Contributing

Thank you for investing your time in contributing to our project!

## Development Setup

1. Install `uv`.
2. Run `uv pip install -e ".[dev,demo]"` to set up the environment.

## Running Tests

Run `pytest` to execute all tests.

## Coding Standards

- We use `ruff` for Python linting and formatting.
- We use `prettier` for frontend, JSON, YAML, and Markdown files.
- We enforce checks via pre-commit hooks.

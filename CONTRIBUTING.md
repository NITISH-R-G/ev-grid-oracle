# Contributing to the Repository

First off, thank you for considering contributing to this repository! It's people like you that make it such a great resource.

## Getting Started

1.  **Fork the repository** on GitHub.
2.  **Clone the project** to your own machine.
3.  **Commit changes** to your own branch.
4.  **Push your work** back up to your fork.
5.  Submit a **Pull request** so that we can review your changes.

## Development Environment

To set up the development environment, please follow these steps:
- Ensure Python 3.12+ and Node.js 22+ are installed.
- Run `uv pip install -e ".[dev,demo]"` to install all required development, test, and demo dependencies.
- Ensure Prettier and Ruff are used for code formatting and linting.

## Code Review

All submissions, including submissions by project members, require review. We use GitHub pull requests for this purpose. Consult GitHub Help for more information on using pull requests.

## Issues

If you find a bug, please create an issue with detailed steps to reproduce it. If you have a feature request, please create an issue detailing the request and the problem it solves.

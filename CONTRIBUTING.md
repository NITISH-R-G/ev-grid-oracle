# Contributing to EV Grid Oracle

First off, thank you for considering contributing to EV Grid Oracle! It's people like you that make EV Grid Oracle such a great project.

## Code of Conduct
By participating in this project, you are expected to uphold our Code of Conduct. Please read the `CODE_OF_CONDUCT.md` file before contributing.

## How Can I Contribute?

### Reporting Bugs
This section guides you through submitting a bug report for EV Grid Oracle.
- Use the issue tracker to report bugs.
- Please provide as much detail as possible to help us reproduce the bug.
- Check if the bug has already been reported.

### Suggesting Enhancements
This section guides you through submitting an enhancement suggestion for EV Grid Oracle.
- Use the issue tracker to suggest enhancements.
- Describe the enhancement in detail and why it would be useful.

### Pull Requests
1. Fork the repo and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. If you've changed APIs, update the documentation.
4. Ensure the test suite passes.
5. Make sure your code lints.
6. Issue that pull request!

## Styleguides
### Git Commit Messages
- Use the present tense ("Add feature" not "Added feature").
- Use the imperative mood ("Move cursor to..." not "Moves cursor to...").
- Limit the first line to 72 characters or less.
- Reference issues and pull requests liberally after the first line.

### Code Guidelines
- We use `ruff` for linting and formatting Python code. Please ensure your code passes `ruff check` and `ruff format`.
- We use `mypy` for static type checking.
- For JavaScript/TypeScript in the `web/` directory, we use `prettier` and `tsc`.

# Contributing

First off, thank you for considering contributing to this repository. It's people like you that make this open-source community a vibrant and educational place.

## How Can I Contribute?

### Reporting Bugs

Before creating bug reports, please check the existing issues as you might find out that you don't need to create one. When you are creating a bug report, please include as many details as possible.

### Suggesting Enhancements

If you have an idea for an enhancement, please submit an issue with a clear description of your proposal.

### Pull Requests

* Fill in the required template
* Do not include issue numbers in the PR title
* Include screenshots and animated GIFs in your pull request whenever possible.
* End all files with a newline.
* Follow the existing coding style and conventions.
* Before submitting your pull request, please make sure your code passes all linting and testing checks by running `./validate-submission.sh`.

## Coding Guidelines

Please follow the coding guidelines described in `AGENTS.md` and ensure you use the tools available like `ruff` and `prettier` for code formatting.

# Contributing Guidelines

Thank you for your interest in contributing to our project! We welcome contributions from everyone.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/PROJECT_NAME.git`
3. Create a new branch: `git checkout -b feature/your-feature-name`
4. Set up the development environment using `uv` and Node.js.

## Development Setup

See the README for specific instructions on setting up the environment.

## Submitting Changes

1. Ensure your changes pass all local tests and linting.
2. Commit your changes with clear, descriptive commit messages.
3. Push to your fork: `git push origin feature/your-feature-name`
4. Open a Pull Request against the main branch.

## Code Style

- We use Ruff for Python formatting and linting.
- We use Prettier for frontend and configuration file formatting.
- Type hints are required for Python code.

## Issues

When opening issues, please use the provided issue templates and fill out all requested information.

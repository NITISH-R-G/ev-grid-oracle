# Contributing to EV Grid Oracle

First off, thank you for considering contributing to EV Grid Oracle! We welcome contributions from everyone.

## Getting Started

1. Fork the repository and create your branch from `main`.
2. Install the development dependencies:
   ```bash
   pip install uv
   uv pip install -e ".[dev,demo]"
   ```
3. Run the local submission checks before pushing:
   ```bash
   ./validate-submission.sh
   ```

## Pull Request Process

1. Ensure your code passes all linting, formatting, type-checking, and tests.
2. Update documentation if necessary.
3. Once opened, an AI reviewer will provide automated feedback. Please address the comments before requesting a human review.

Thank you for contributing!

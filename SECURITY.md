# Security Policy

## Supported Versions

Only the latest version on the `main` branch is actively supported with security updates.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.
Instead, report them privately via GitHub Security Advisories or to the repository maintainers directly.

Our automated systems continuously run Dependabot, CodeQL, TruffleHog, and Trivy to proactively identify and resolve security issues.
